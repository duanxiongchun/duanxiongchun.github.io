# 🧠 镜像与反转图形题目完美对齐设计文档 (SVG Dynamic Grid Alignment)

## 1. 概述
在**脑力认知研究所**项目中，部分涉及“空间想象与旋转/镜像”以及“图形矩阵推理”的题目，目前在 `questions.js` 中使用文本字符矩阵的形式进行定义（例如 `'⬛⬜⬜\n⬜⬛⬜\n⬜⬜⬛'`）。
由于不同的操作系统（iOS/macOS、Android、Windows）和浏览器使用了不同的 Emoji 字体，字符字宽、字高和基线对齐方式存在物理差异，使用普通 `div` + CSS Flexbox/Grid 拼装排版时，经常在部分设备上出现行高偏差、错位换行，甚至完全错乱的问题。

本方案通过**重构渲染引擎**，引入一套 **SVG 动态矩阵渲染器**。该渲染器在运行时自动解析矩阵字符串，生成纯矢量 (SVG) 的完美单元格，核心元素使用 SVG 矢量几何图形渲染，其余元素利用 SVG `<text>` 的 `dominant-baseline` 和 `text-anchor` 特性强力居中，彻底消除设备差异带来的错位。

---

## 2. 核心技术设计

### 2.1 矩阵判定算法 (`isGridString`)
系统在加载选项或原图内容时，需首先检测内容是否为需要渲染为格子的矩阵数据：
* 如果内容是 `string` 且包含换行符 `\n`，判定为**多行矩阵**。
* 如果内容是 `string` 且长度为 `1` 到 `4` 个字符，且内容中包含预定义的矩阵格标识符（如 `⬜`, `⬛`, `🔴`, `🟢`, `🟡`, `🔵`, `⭐`, `🍊`, `🎈`, `b`, `p`, `q`, `d` 等），判定为**单行矩阵**。
* 其余字符（如普通词汇 `"90°"`, `"大红色"` 等）判定为**普通文本**，跳过 SVG 渲染直接返回原样。

### 2.2 SVG 坐标与布局公式
* **单元格宽高**：每个格子定义为固定的 `40` x `40` 虚拟像素。
* **视口大小 (viewBox)**：如果矩阵有 `C` 列，`R` 行，则生成的 SVG 的 viewBox 设为 `0 0 (C * 40) (R * 40)`。
* **单元格定位**：
  * 格子底板：圆角矩形 `<rect x="c*40 + 2" y="r*40 + 2" width="36" height="36" rx="6" />`。
  * 空白背景（`⬜`）：亮灰边框，融入背景色。
  * 实心背景（`⬛`）：亮蓝色/靛蓝色边框与阴影。

### 2.3 符号标准映射表 (SVG Vectors)
对于核心几何形状，我们将直接绘制高保真的矢量元素，代替 Emoji 原生的丑陋或非标准渲染：
1. **圆形 (🔴/🟢/🟡/🔵/🟪/🟨/🟧...)**：
   * 绘制 SVG `<circle cx="c*40 + 20" cy="r*40 + 20" r="13" />`，填充对应的优质 Tailwind 色值。
2. **星星 (⭐/🌟...)**：
   * 绘制五角星 `<path>` 路径，并以 `(c*40 + 20, r*40 + 20)` 为几何中心进行平移与缩放，填充亮黄色。
3. **箭头 (➡️/⬅️/⬆️/⬇️/↗️/↘️/↖️/↙️...)**：
   * 绘制标准矢量箭头路径，根据不同符号进行角度旋转（如 `0°`, `90°`, `180°`, `270°`, `45°` 等）。
4. **字母兜底与复杂 Emoji**：
   * 采用 SVG `<text>` 渲染，以 `x = c*40 + 20`, `y = r*40 + 20` 为原点。
   * 设置属性：`dominant-baseline="central"`（使文字垂直几何中心对齐）和 `text-anchor="middle"`（使文字水平几何中心对齐），保证 100% 居中。

## 3. 集成与修改范围

### 3.1 `logic/js/games.js` & `logic/js/games/spatial.js`
* 重构核心渲染入口 `renderOptionContent(opt)`。
* 编写内置 SVG 发生器，支持上述映射与自动计算。

### 3.2 `logic/js/games/pattern.js`
当前矩阵推理模块渲染 3×3 格子时直接输出 `cell` 字符，我们需要将其封装：
```diff
- ${i===8 ? '❓' : cell}
+ ${i===8 ? '❓' : renderOptionContent(cell)}
```
当前选项按钮渲染也是直接输出：
```diff
- ${item.o}
+ ${renderOptionContent(item.o)}
```

## 4. 影响与测试验证
* **向后兼容性**：不改变 `questions.js` 数据结构，旧数据无需做任何手动清洗或重新录入。
* **对齐一致性**：在 Safari、Chrome、Firefox，以及 iOS、Android、Windows 设备上打开游戏界面，测试多行星星矩阵、单行箭头与水果等题目，确保全部格线严密贴合，没有任何上下浮动或溢出。
